# 0.4 — New note in the traditional notes application

Starting condition: `/exampleapp/notes` is already open. The user types a note and saves the form. Requests below assume caching is disabled, as in the course demonstration.

```mermaid
sequenceDiagram
    actor user
    participant browser
    participant server

    user->>browser: Type a note and click Save
    browser->>server: POST /exampleapp/new_note (form field: note)
    Note right of server: Append the note and its creation date to the in-memory notes array
    server-->>browser: 302 Found, Location: /exampleapp/notes
    browser->>server: GET /exampleapp/notes
    server-->>browser: 200 OK, HTML document
    browser->>server: GET /exampleapp/main.css
    server-->>browser: 200 OK, stylesheet
    browser->>server: GET /exampleapp/main.js
    server-->>browser: 200 OK, JavaScript
    Note right of browser: Execute main.js and register the response callback
    browser->>server: GET /exampleapp/data.json
    server-->>browser: 200 OK, JSON notes including the new note
    Note right of browser: The callback parses the JSON and builds the notes list in the DOM
```

The POST triggers a redirect and a full document reload. The CSS and JavaScript requests may run concurrently; their drawn order does not imply that one depends on the other. The JSON request is initiated by the downloaded JavaScript.
