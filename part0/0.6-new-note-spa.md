# 0.6 — New note in the single-page application

Starting condition: `/exampleapp/spa` is already loaded.

```mermaid
sequenceDiagram
    actor user
    participant browser
    participant server

    user->>browser: Type a note and click Save
    Note right of browser: The submit handler calls preventDefault() to stop normal form navigation
    Note right of browser: Create a note with content and date, append it to the local array, and clear the input
    Note right of browser: Redraw the notes list immediately using the updated local array
    browser->>server: POST /exampleapp/new_note_spa, Content-Type: application/json, body: content and date
    Note right of server: Append the submitted note to the in-memory notes array
    server-->>browser: 201 Created
    Note right of browser: Stay on the same document; no redirect or additional data fetch is required
```

The browser renders the new note before receiving the POST response. This is an optimistic update; the diagram describes the successful path and does not claim that the sample handles a failed request. Unlike exercise 0.4, saving makes only one HTTP request.
