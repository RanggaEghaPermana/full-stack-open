# 0.5 — Loading the single-page notes application

Starting condition: the user navigates to `/exampleapp/spa`, with caching disabled.

```mermaid
sequenceDiagram
    actor user
    participant browser
    participant server

    user->>browser: Navigate to /exampleapp/spa
    browser->>server: GET /exampleapp/spa
    server-->>browser: 200 OK, HTML document
    browser->>server: GET /exampleapp/main.css
    server-->>browser: 200 OK, stylesheet
    browser->>server: GET /exampleapp/spa.js
    server-->>browser: 200 OK, JavaScript
    Note right of browser: Execute spa.js and register callbacks, including the form submit handler
    browser->>server: GET /exampleapp/data.json
    server-->>browser: 200 OK, JSON notes
    Note right of browser: Parse the response into the local notes array and render the list in the DOM
```

The initial load still fetches HTML, CSS, JavaScript, and note data. The SPA behavior becomes especially visible when adding a note: the form handler updates the existing page instead of loading a new document. CSS and JavaScript can be requested concurrently.
